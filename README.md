# dsh-wechat-friendly

在微信里远程使用 DeepSeek Harness：手机发消息，电脑上的 DSH 干活。

这是 [dsh-wechat-plugin](https://github.com/xcisxc29/dsh-wechat) 的二次开发版（fork）。连接微信的框架沿用上游，主要改动集中在**指令层**和**展示层**：全部指令中文化并精简，会话列表、工作区列表、指令总表改成**图片卡片**，并支持**多实例（分身）各自独立绑定**。

不需要公网 IP，不需要内网穿透。走腾讯官方 iLink Bot 网关，扫码后机器人就和你的微信号绑定。

## 特性

- **双向文字**：微信消息变成 DSH 的 prompt，回复再回到微信。
- **图片、文件、语音、视频**双向收发；附件落到会话工作区，交给 agent 处理。
- **中文指令 / 24 条**：`/帮助` `/工作区列表` `/会话列表` `/模型` `/切换` `/新会话` `/权限` `/模式` `/聊天记录` `/当前` `/停止` `/其余` `/继续` `/等待` `/完成` `/发送` 等，全部有中文名；旧英文名保留为隐藏别名，自然语言也能用（「换个对话」「看下有哪些对话」）。
- **`/发送`**：不给参数时发一份全部工作区与会话的清单 md（编号、最近使用时间、最近回答前 20 字）；`/发送 工作区-会话`（可用编号）则只把**下一条**消息发给那个会话，不切换当前会话；先 `/等待` 攒内容、再 `/完成` 也能把整批发给目标会话。目标会话仍然是「其他会话」，它的回答按离开判定规则汇总成 md，不会挤进当前对话。
- **图片卡片**：工作区、会话、指令总表，以及模型 / 权限 / 模式 / 当前 / 聊天统计，都渲染成 JPEG 卡片发到微信；会话行带最近一条聊天片段，分页、编号、分支折箭头齐全，默认每页 10 行；五种主题（深色科技 / 浅色简洁 / 渐变玻璃 / 暖纸手帐 / 终端极客）+ 强调色可配。
- **模型与思考等级**：`/模型` 看清单与当前选择，`/模型 编号-等级` 一次切换两者。
- **权限与模式**：在微信里查看 / 切换会话权限（仅可查看 / 工作区内修改 / 完全权限 / 自动审查）；查看 / 切换会话模式（模式只能在还没开始聊天的会话里换）。
- **聊天记录**：`/聊天记录` 看会话统计卡（总聊天次数、上下文比例、计费 token、第一次 / 最后一次时间），`/聊天记录 5` 把最近几条导出成 md 文件发到微信（文件名含会话名、条数、时间戳）。
- **长列表多卡**：列表超过 10 条时最多连发 5 张卡，更多的回复 `/其余` 继续。
- **`/继续`**：回复窗口快到上限时，发一条 `/继续` 只刷新窗口、不发给模型，用来把排队中的回复接着发完。
- **离开才同步其他会话**：锁屏或离开电脑（默认 5 分钟无操作，可设置 0-120 分钟）时，非当前会话的回答会汇总成一个 md 文件发到微信，文件名形如 `来自｛工作区-会话名称｝的回复｛时间戳｝.md`；如果这条回答在桌面端等你确认或选择，则加 `需确认：` 前缀并以 `# 【工作区-会话名称】` 开头，避免多任务时逐条轰炸。
- **`/等待`**：进入暂存状态，之后发的文字、图片、文件都先攒着，`/完成` 时合并成一条交给模型。
- **审批与选择题**：权限申请、决策、选项都能发到微信，回数字即可。
- **设置页**：**Settings → WeChat（友好版）**，卡片主题、页数、提示词、发送上限、指令别名、聊天记录条数等都能改。
- **多实例（分身）隔离**：状态文件、工作区、日志按实例派生，桌面和分身各用各的；同一台机器上多个实例不会互相覆盖。

## 安装

在 DSH 的插件市场页或通过 `plugin_manager` 安装本地目录（本仓库根目录即插件包）：

```bash
plugin_manager action=install_bundle target="<本仓库绝对路径>"
```

安装后到 **Settings → WeChat（友好版）** 点击启动 / 扫码登录。首次扫码会把机器人绑定到你的微信号。

> 与上游 `dsh-wechat-plugin` 是替换关系，**不要同时启用**：两者使用同一个通道服务名、路由前缀和工具名，同时加载会在启动时冲突。

## 指令

| 指令 | 说明 |
| --- | --- |
| `/帮助` | 全部指令（图片卡片） |
| `/工作区列表` | 全部工作区（图片卡片）；`/工作区 名称` 进入指定工作区的会话 |
| `/会话列表` | 当前工作区的会话（图片卡片，带最近一条聊天片段） |
| `/模型` | 模型与思考等级（图片卡片）；`/模型 编号-等级` 同时切换 |
| `/切换` | 工作区卡片；`/切换 工作区` 浏览其会话；`/切换 会话` 切过去；`/切换 工作区-会话` 一步到位 |
| `/发送` | 全部工作区与会话清单（md，含编号、最近使用时间、最近回答摘要） |
| `/发送 工作区-会话` | 把下一条消息发给该会话（可用编号），不切换当前会话；兼容 `/等待` |
| `/新会话 [标题]` | 立即新建会话并切过去；开始聊天前还能用 `/模式` 改模式 |
| `/权限` / `/权限 完全` | 查看 / 切换权限（仅可查看 / 工作区内修改 / 完全权限 / 自动审查） |
| `/模式` / `/模式 聊天` | 查看 / 切换模式（仅未开始聊天的会话） |
| `/聊天记录` | 会话统计卡（总条数、上下文比例、计费 token、首末时间） |
| `/聊天记录 50` | 导出最近 50 条为 md 文件（1-100） |
| `/其余` | 列表卡片超过 5 页时继续发下一批 |
| `/继续` | 只刷新微信回复窗口，不发给模型（回复被上限挡住时用） |
| `/等待` | 开始暂存文字 / 图片 / 文件，直到 `/完成` |
| `/完成` | 把暂存内容合并后一起交给模型 |
| `/当前` | 当前会话卡（名称、模型、权限、模式） |
| `/停止` | 终止当前思考或任务 |

分隔符可以用空格、「：」或「/」，例如 `/切换/会话名`、`/停止：`。指令名（触发字后面的词）可以在设置页逐条改，留空用默认名；旧英文名（`/help` `/list` `/switch` `/new` `/model` `/permission` `/mode` `/history` `/current` `/cancel`、`/workspace`）仍然可用。自然语言也可以，DSH 会先说明它要做什么，你同意后再执行。

## 图片卡片

- 只对列表 / 信息类结果出图：工作区、会话、指令总表、模型、权限、模式、当前、聊天统计。其它回复保持文字。
- 卡片宽度 750 CSS px、2 倍图（1500 px）、JPEG。
- 会话卡：大标题是工作区名，主会话带编号，分支会话在下面、用「一横 + 向上折箭头」标识，编号连续；当前会话左侧有高亮条。
- 分页：每页 10 行，页脚提示「回复编号切换」；翻页后编号连续，图片和文字列表共用同一套编号。
- 主题在设置页切换：A 深色科技 / B 浅色简洁 / C 渐变玻璃 / D 暖纸手帐 / E 终端极客 / 纯文字。

## 权限与模式

- 权限预设四个：**仅可查看**（read-only）、**工作区内修改**（workspace-write）、**完全权限**（danger-full-access）、**自动审查**（auto，实验特性：完全权限 + 每一步交给电脑端审查）。
- 放宽权限只影响之后的操作；收紧不会撤回已挂起的审批。微信会话默认跟随桌面端 / 实例自身的权限配置，不再单独设置（需要时在微信里用 `/权限` 查看或临时切换）。
- 模式即 DSH 的 Agent 预设（standard / ptc / minimal / cordis / chat 等）。DSH 规定模式只能在会话第一轮对话开始前选择；已开始的会话会被拒绝，提示你用 `/新会话` 新建后再选。

## 多实例（分身）

- 每个实例（桌面本体或任一分身）都可以单独启用本插件。
- 状态文件、默认工作区、诊断日志按实例派生：
  - 桌面实例：`<DSH_HOME>/wechat/state.json`、`<DSH_HOME>/dsh_wechat`、`<DSH_HOME>/wechat/boot.log`
  - 分身实例：`<DSH_HOME>/wechat/instances/<实例 key>/state.json`、`<DSH_HOME>/dsh_wechat/<实例 key>`、同目录 `boot.log`
  - 实例 key 默认取 `DSH_INSTANCE_ID`（分身后台注入），也可在设置页手动指定。
- 一个实例一个机器人：每个实例用自己的微信号扫码，就会各自得到一个机器人。
- 同一个微信号能否再开第二个机器人，取决于腾讯网关（上游实现「重新扫码」是复用已有绑定，不会新建）；如需多机器人，建议每个实例用不同微信号。桌面和分身同时长轮询同一个机器人时消息归属不确定，避免这样用。
- 从上游迁移：桌面实例可以把旧的 `<DSH_HOME>/wechat/state.json` 直接复制过来沿用绑定；分身实例不要复制，否则会共用同一个机器人。

## 设置项

设置页在 **Settings → WeChat（友好版）**，尽量精简，只留下常用的几项：

- **帮助**：使用手册入口。
- **连接**：启用 / 停用通道、查看绑定账号、扫码或重新连接。
- **行为**：微信对话提示词（presenceNote）、允许其他会话推送到微信、连续发送上限、静默合并时长、长回复转文件阈值、不认识指令时怎么猜（后台 AI 猜测 / 仅本地提示 / 不提示）。
- **展示**：列表用图片卡片、卡片主题、强调色、最近回答摘要字数（0-300）。
- **指令**：21 条指令的名称与含义，逐条可改别名（留空用默认名）。
- **诊断**：日志文件、状态文件、最近日志。
- 附件不再需要设置：发来附件后默认等你补一句话说明要做什么；第一次发附件时程序会提示一次，之后不再重复提示。
- 指令执行前默认先向你确认，按 DSH 的默认行为，不再单独提供开关。

## 故障排查

- **图片发不出去**：微信只允许在回复窗口内发媒体（收到新消息后的一段时间）。窗口已关闭时文字会排队，图片不会——等你在微信里再发一条消息，卡片会作为回复发出。
- **连续发送上限**：一个回复窗口最多 10 条消息，第 9 条会提醒续期；超长回复（默认 4000 字）会转成 md 文件发送。
- **卡片渲染失败**：会在 `boot.log` 记一行，并自动回退成文字列表，不会丢内容。
- **诊断日志**：桌面实例在 `<DSH_HOME>/wechat/boot.log`，分身实例在同级 `instances/<key>/boot.log`。

## 开发

`npm install` 后可直接运行（发布物即源码，无构建步骤）：

```bash
# 语法检查
node --check lib/host.js && node --check dist/core/lib/router.js && node --check client.js
```

修改任何 Host 侧代码后需要重启 DSH；只改 `client.js` 刷新页面即可。
